Cloud Sync Setup
Uses Firebase Realtime Database — free, works on all devices including iPhone. Takes about 5 minutes to set up once.
Setup Steps
  1. Go to console.firebase.google.com and sign in with Google
  2. Click Add project → give it any name → Continue through the steps
  3. In the left sidebar, click Build → Realtime Database
  4. Click Create Database → choose any location → select "Start in test mode" → Enable
  5. Copy the URL shown at the top of the database panel — it looks like:
    https://your-project-default-rtdb.firebaseio.com
  6. In the left sidebar go to Project Settings (gear icon) → Service accounts → Database secrets → click Show and copy the secret
  7. Paste both below and click Connect
